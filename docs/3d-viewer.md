# 解剖人体的 3D 动作回放

身体协同页默认「3D 动作回放」：骨骼与肌肉网格直接跟随当前帧的姿态运动，展示引拍、挥拍、击球和随挥。另一个视图「视频 / 2D 骨架对照」供核对原数据。选择动作阶段、击球事件或曲线峰值后，3D 人体与测量数据一起定位到同一个采集帧。

## 运动人体模型

- 本地 GLB：`apps/web/public/models/anatomy/body.glb`，约 2.5 MB，221 个网格：218 个独立肌肉区域、完整骨骼、头手足肌肉及结缔组织。无需外部 CDN 或 Draco 解码器。
- `anatomyRig.ts` 在运行时为原始网格建立 15 个控制关节和 GPU 蒙皮绑定，分组后为 251 个可独立隐藏的网格。骨表面按连通组件刚性绑定，肌肉与跨关节结缔组织使用混合权重，保持固定肢段长度。`Body3DViewer.tsx` 负责播放、时间定位、部位选择和观察视角。
- 象牙色骨骼与珊瑚色肌肉保留参考图的结构外观。模型会随时间轴改变动作，不再把静态解剖图作为主视图。
- 下肢、躯干、上臂、前臂的选择联动页面曲线。慢放和逐帧帮助观察关节方向、肢体位置及手腕轨迹；肌肉网格的移动不代表已测得真实肌肉收缩。
- 模型比例来自标准解剖素材，不是对用户身体的扫描。肌肉名称与结构类别来自模型元数据，中文词表在 `anatomyCatalog.ts`。
- 来源：Fit Mit With anatomy atlas，派生自 Z-Anatomy / BodyParts3D。保留原 GLB 文件，运行时建立动画绑定并调整材质与可见层。署名和许可证随模型分发。
- 加载失败或 WebGL 不可用时，仍可切到视频对照。切换视图和卸载需要停止播放、取消下载并回收渲染资源。

## 这是什么数据

当前 Worker 输出的是归一化图像坐标。「3D 动作回放」把可信关键点映射到立体场景，用关节方向驱动解剖人体的运动骨架。通用点位转换保留固定左右深度间隔，但解剖骨架求解只使用 XY，不能将这个示意间隔当作深度观测计算身体或头部旋转。深度并非从视频估计或测量得到。

头部朝向继承躯干，只允许可靠且与肩部左右顺序一致的耳/眼点对驱动有限的画面内侧倾；鼻点不再单独驱动三维头颈旋转。脸点缺失或明显偏离头部区域时隐藏头部，不保留旧姿态。肩线接近重合时使用可分辨的髋线；两者都无法分辨时隐藏身体，避免虚构朝向。肘、膝与踝从父骨方向求解并限幅，保持固定肢段长度。这些限幅用于抑制异常显示，不是个体关节活动范围的测量，也不能恢复真实的转头、出平面运动或解决所有自相交。

因此动态视图保留「二维姿态驱动 3D 动画」标识，并说明前后深度与球拍位置为示意。相机预设指查看器中的虚拟观察方向，不代表已经获得该方向的真实拍摄画面。旋转模型不会增加观测信息。

两种来源均保持同一限制：

- 合成演示：人工生成的二维运动，以示意深度立体化；不代表标准发力或理想动作。
- 用户视频：真实二维姿态结果，以同样的示意深度立体化；不宣称完成三维重建。

`SkeletonRef.keypoints3dKey` 仍是未来数据字段。本版本不读取它，不能因字段存在就把结果标为真实三维。

## 时间与数值

播放使用采集时间戳和实际经过的时间。逐帧、外部阶段跳转及曲线峰值跳转均落到已有采集帧，避免用固定播放帧率重新构造时间。

相机旋转、缩放、网格形状和显示深度均不参与指标计算。已有肘角、相对高度、投影速度及身体运动曲线仍来自二维关键点；不能由当前模型计算真实关节力矩、肌肉激活、转体角或力量传递效率。

## 缺失数据与降级

置信度不足的点不应被补成原点，也不应沿用上一帧的姿态。缺失点关联的实体部位应隐藏，以免连续表面暗示数据完整。

3D 场景在整个片段使用稳定的尺度和参考位置，避免逐帧归一化制造身高变化或漂移。坐标是示意场景单位，不是米；地面与网格不意味着已经完成地面标定。

WebGL 不可用或上下文丢失时，应展示明确提示并允许回到原视频视图。视图切换和卸载需停止播放/渲染循环，释放场景几何体、材质、控件监听器及渲染器资源。

## 核验重点

1. 旋转和相机预设改变观察方向，但不改变帧编号或数值。
2. 阶段、事件和峰值跳转同步更新姿态；播放期间外部定位会停在所选帧。
3. 3D 与原视频切换保留所选帧，同一时刻只有一个播放时钟。
4. 遮挡样例中的手腕或肘缺失时，相应实体部位消失，不保留旧姿态。
5. 反复切换视图不残留旧 canvas；缩放和移动端布局不挤出页面宽度。
6. 无 WebGL/上下文丢失路径可见、可理解，原视频仍可查看。

## 绑定动画的验证范围

除了既有时间轴、坐标映射和指标检查，还需核验不同姿态下的解剖网格变化：肩肘屈伸、膝踝移动、躯干变化应带动对应骨骼与肌肉；模型不能停留在站立参考姿态。准备、击球与随挥至少三个时间点应呈现不同动作，跳帧与慢放应保持网格、手腕轨迹和下方数值同步。

当前 51 项 TypeScript 测试和 24 项 Python 测试通过，生产构建通过。解剖绑定的 11 项测试覆盖实际 GLB 的骨骼/肌肉运动、固定肢段长度、纯采样、缺失恢复、正背身头身朝向、鼻点误检、脸点侧倾限幅、示意 Z 隔离、肘膝足限幅及斜方肌颅骨附着。Worker 测试覆盖低置信度隔离、双向滤波在缺失/时间间隙处重置和高速动作的峰值保留。
