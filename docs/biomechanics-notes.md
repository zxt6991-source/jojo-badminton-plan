# 身体协同视图：测量与解释

新增默认的「身体协同」视图；原数值卡保留在「基础指标」。阶段按钮、身体区域示意、彩色骨架、手腕轨迹、角度变化曲线与视频共用帧编号和采集时间戳。颜色仅标识区域，不编码肌肉激活或受力。

## 已实现的测量

- 下肢：对每条连续可见腿独立计算膝弯曲角的变化速度，再平均，避免一侧突然遮挡产生假峰值。
- 躯干：髋中点至肩中点连线在图像平面内的方向变化速度。
- 持拍上臂/前臂：肩至肘、肘至腕连线的图像平面方向变化速度。
- 击球参考帧：膝弯曲、躯干倾斜、上臂方向、肘弯曲及手腕投影速度。手腕速度以躯干长度/秒表示，不是球拍速度或球速。

计算前以宽高比修正图像归一化坐标。角速度以采集时间的中心差分计算，角度跨越 ±180° 时先解缠。缺失或中心差分跨越超过 50ms 的间隔不求导。速度要求至少名义 60fps；当前只在可信的侧面/斜侧图像中显示。连续有效样本覆盖不足 70% 时隐藏该区域曲线；这属于未校准的工程门槛，不是动作质量评分。覆盖率与测量置信度不同，机位或帧率不合适时，高覆盖率也不会解锁曲线。

阶段只使用已有三个时点：引拍起点、击球、随挥结束。「挥拍过程」是引拍起点到击球的观察区间；未声称完成精确加速阶段分割。不补全缺失阶段。峰值指当前观察窗内的画面角度变化峰值，不代表最大肌肉发力时刻。

## 解释边界与依据

[King 等，2020，羽毛球跳杀运动学研究](https://www.stuartmcnaylor.com/publication/badtech1/King_et_al_2020.pdf) 使用 18 名有经验球员的三维运动数据分析相关性。它支持从全身协同而非单个肘角理解动作，但其群体关联不能成为当前用户的合格阈值。肩内旋、前臂旋前和骨盆—胸廓分离角不能由本模块的二维线段角度替代。

[OpenCap，2023](https://doi.org/10.1371/journal.pcbi.1011462) 将视频、三维运动学和肌骨动力学仿真结合，用于估计动力学量。当前工程尚无该类仿真，不输出关节力矩、地面反作用力、能量传递效率、肌肉激活或负荷评分。

「峰值先后」仅描述可见运动的时序。不同区域使用不同角度定义，即使单位相同，也不能将曲线高度转写成身体部位的力量贡献排名。

## 验证

新增数值测试覆盖：不规则采集时间、画幅比例、静止零值、一侧膝盖遮挡造成的平均成员变化、缺失长间隔、低帧率、低置信度、不适合视角、未知持拍侧与缺失阶段边界。演示的全身运动是明确标识的人工合成数据，不是标准发力范本或真实推理证据。
