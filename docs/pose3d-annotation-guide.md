# 3D 研究素材与人工标注规范

更新：2026-11-19。本规范对应 v1.1 的 P0 数据工作。它定义待收集的证据，不把已有研究候选、模型预测或合成测试转为人工真值。当前两段授权视频只有一段具备成功的 2D 输入；从同一视频选择三个窗口仍只计一个来源。

## 素材记录

POC 需要侧面、斜侧、转身或遮挡各至少一段可用授权视频。每段保留原片与实际分析代理、二者 hash、授权用途、保留期限、已知采集帧率和处理历史。未知帧率或是否变速应明确写未知；容器帧率和代理 PTS 一致不能证明原始采集时钟。

既有两段视频只获本机内部验证授权，不上传。研究授权允许保留期限为空；正式评估工具要求明确且未过期的 `retentionUntil`，应由数据负责人提供，不能为了通过校验自行编造日期。研究窗口配置中的 `humanVerified:false` 保持原样，人工标签另存记录。

按球员与拍摄场次分组划分 `calibration`、`validation`、`test`；同一原片裁剪出的片段不能跨组当成独立样本。记录持拍侧、机位、遮挡和转身时段；这些描述由人工核对，不能直接继承启发式视角预测。

## 人工检查顺序

1. 先看原始视频与同帧图像，确认目标球员、左右侧和动作阶段。采样帧是零起始索引，时间从对应 `timestamps.f32` 读取；不要用视频播放器四舍五入的秒数反推帧。
2. 标出可确认的击球帧及引拍/随挥范围，无法确认的事件保留原因，不能因为模型已有候选就确认击球。连续研究窗口前后约一秒仅为采样选择，尚不是生产自动窗口策略。
3. 标注采样帧或时段的机位：`side`、`oblique`、`front`、`rear`、`unknown`。转身时可以给逐条深度标签与复核记录覆盖 `viewClass`，避免整段机位标签掩盖变化。
4. 在查看模型深度前标注能从画面独立判断的关节近远关系，减少被模型预测影响。不能判断的关系放入“未判定”记录，不强选近远，不参与序数准确率分母。
5. 再逐模型检查左右交换、人物切换和严重错误。只有实际复核过的帧才写布尔标签；未复核不等于 `false`。错误定义和采样规则在看结果前记录，并保留复核分歧及处理理由。

## 索引与文件格式

身体常用关节采用人体自身的左右，和观看者左右不同：

| 部位 | 左 | 右 |
| --- | ---: | ---: |
| 肩 | 5 | 6 |
| 肘 | 7 | 8 |
| 腕 | 9 | 10 |
| 髋 | 11 | 12 |
| 膝 | 13 | 14 |
| 踝 | 15 | 16 |

以上索引在 WholeBody-133 与项目 cwb-65 的身体部分一致。正式评估全部使用 cwb-65：`[0..22] + WholeBody[91..132]`；不要把人脸的 68 点索引带入 65 点数据。

正式 manifest 的 `ordinalDepth` 条目形如 `{frame,a,b,closer:"a"|"b",viewClass?}`，表示 a 或 b 哪一个更接近相机。同帧同一无序关节对只能出现一次。无法判断、相等或存在争议的条目保存在独立标注日志中；当前评估器不支持把 `closer` 写成 `unknown`。`manualHitFrames` 仅包含确认过的帧。

逐模型 `manualReview` 条目包含 `{frame,leftRightSwapped,identitySwitch,severeError,viewClass?}`。在单独的本机日志保存标注者、复核者、日期、查看材料的 hash、未判定条目和争议处理；这些不能从模型输出生成。已有评估器不自动证明人工记录的来源，因此复核日志是必要的外部证据。

完整 manifest 与 run 格式见 [实施记录](pose3d-implementation.md)。每个 run 必须通过 `provenance.inputVideoSha256` 绑定对应原视频；同帧数、同时间轴不足以绑定来源。正式 manifest 目前保持为空且未冻结，RAW 探针与连续窗口报告另存，避免将研究成功误标为已通过正式验收。

## 结果解释

相同帧的 A/B 预测一致只是模型间一致性，不能代替人工近远标签。未预测的标签单独进入 coverage，不能当成正确或从分母中消失。骨长变化、肘角跳变及不同相机假设下的差异可帮助挑选复核帧，但不能据此给球员动作评分。

完成标注后，先核对片段授权、分组、未判定记录和数据 hash，再冻结清单及指标方案。模型选型、视角门控和窗口策略需要分层结果；仅看总体均值或单段视频不能确认已满足 POC。
