# Metrics 0.1.0

`calculateMetrics(video, analysis, timestamps, keypoints)` is independent of the pose backend. Timestamps and keypoints are decoded `Float32Array`s. Geometry converts x into image-height units before angles/distances, avoiding aspect-ratio distortion from normalized coordinates. Height uses hip-center y minus wrist y divided by shoulder-to-hip-center length. Offset uses the held-side shoulder and a consensus of visible toes/heels and nose relative to the torso; ambiguous heading suppresses it.

Each metric averages relevant joint confidence over ±100 ms and additionally requires reliable joints at impact. Confidence is the minimum of the local average, impact confidence, view confidence, and any facing confidence. These uncalibrated scores are reliability bounds, not independent probabilities to multiply. Elbow measurements in front/back views apply a 0.85 penalty to the view-confidence bound. Values below 0.5 confidence are hidden. Temporal metrics use phase-boundary capture timestamps, and require nominal 60 FPS (59 FPS cutoff to include 59.94 capture rates, aligned with the worker quality tiers). Missing phases, unknown handedness, degeneracy, and ambiguous heading use `low_conf`. Unsupported views use `bad_view`. No values are labeled good/bad and no coaching diagnoses are generated.

`elbowAngleSeries` returns frame-indexed angle samples for chart rendering; null samples must remain gaps. Changing formulas, phase definitions, or confidence thresholds requires incrementing `DEFINITION_VERSION` and rerunning the full evaluation dataset. Synthetic tests establish formula correctness, not validity against human-labeled video.
